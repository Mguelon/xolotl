# Design context — Xólotl

**Product.** Two tools behind one landing page (`/`): the swap (`/swap`: the person in a 5–15 s clip becomes the character in one image, on the user's own GPU with ComfyUI + MiniMax H3 + SAM 3.1, fully open weights) and the character creator (`/create`, in the works), which makes the characters the swap casts. Entry for Comfy's Open Source Higgsfield Challenge (the "Openjutsu" prompt).

**Audience.** ComfyUI users and creators with a 16–24 GB NVIDIA card who want a Higgsfield-style tool without accounts or credits; the challenge judges running it for 5–10 takes; people who found it on social media.

**Jobs to be done.** Drop a clip and a character → see the swap next to the original → download it → open the exact workflow in ComfyUI. Know honestly how long it takes (≈5 min per 5 s and 11 min per 10 s at 480p on an RTX A4000 16 GB).

**Tone.** Dark premium-tech with ONE accent (lightning green on obsidian — Xólotl is the god of lightning and transformation). Professional and warm, never cute, never hype. References the owner likes: Linear, Apple bento, klingai, replicate, ideal.house. No serif, no light "paper" palettes, no WebGL backgrounds, no glass everywhere.

**Signature.** The "twin" viewer: original and swap in one frame with a draggable divider, synchronized. Motion is tied to interaction (drag, hover, state), respects reduced-motion.

**Constraints.** Next.js 16, React 19, plain CSS (no Tailwind), self-hosted OFL fonts (Syne display, Instrument Sans text), works offline, English UI with Spanish, no placeholders — the examples are real generated clips.
